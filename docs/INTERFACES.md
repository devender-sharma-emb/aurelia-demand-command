# Hand-off contracts (draft for review with the other stream teams)

Marketing & Demand is the only stream built in the 3-week window. Merchandising and Sourcing are
stubbed inside this repository against these contracts. If the owning teams change a shape, only the
stub needs to change.

All messages are JSON. `request_id` is generated by the orchestrator and appears in the audit log.

## To Merchandising: allocation request

```json
{
  "request_id": "AR-0001",
  "type": "allocation_request",
  "market": "C",
  "category": "home",
  "reason": "demand spike, competitor price cut",
  "units_requested": 5200,
  "units_available_uncommitted": 3540,
  "horizon_days": 14,
  "campaign_scale": 0.68
}
```

Response:

```json
{ "request_id": "AR-0001", "status": "accepted | partial | rejected", "units_allocated": 3540, "note": "" }
```

## To Sourcing: replenishment request

```json
{
  "request_id": "RR-0001",
  "type": "replenishment_request",
  "category": "home",
  "market": "C",
  "units_requested": 1700,
  "needed_by_days": 14,
  "preferred_mode": "air | sea | any"
}
```

Response:

```json
{ "request_id": "RR-0001", "status": "accepted | rejected", "mode": "air", "lead_days": 7,
  "estimated_cost_eur": 0.0, "note": "" }
```

## To Logistics and Commerce: service-level signal (informational)

```json
{ "type": "service_signal", "market": "C", "category": "home", "expected_uplift_ratio": 1.45,
  "window_days": 14 }
```
